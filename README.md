# AI-Working-Rules-for-Games

Originally made for Unity-MCP work, it is model agnostic and ready to paste into your favorite AI agent.

These rules keep an AI coding assistant from overstepping in a Unity project. The assistant changes only what it is asked to change and proves a fix by running it before calling it done. Balance values and anything set up by hand in the editor stay off limits until the user approves. A last section covers 3D modelling.

How to use

Paste AI_WORKING_RULES.md into the assistant at the start of a session.
